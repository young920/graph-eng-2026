### 1.3 像素 diff 转场检测

```python
import numpy as np
from PIL import Image

# 相邻帧 diff
for i in range(1, len(arrs)):
    a, b = arrs[i-1][1].astype(np.int16), arrs[i][1].astype(np.int16)
```

**关键阈值**：相邻 100ms 帧像素 diff > 0.5% 视为动效存在；> 1.5% 视为动效峰值。

### 1.4 视觉理解模型选择

**问题**：vision_analyze 工具（kimi-k2.6-claude）一直 503 / 配额耗尽
- 错误：`503 engine is overloaded`
- 错误：`429 You have exceeded the monthly usage quota`（8月10日重置）

**解决方案**：直接用 curl 调用 qingxiaoyun 的其他视觉模型

```bash
curl -X POST https://ai.qingxiaoyun.net/v1/chat/completions \
  -H "Authorization: Bearer sk-..." \
  -d '{
    "model": "doubao-seed-2.0-pro",
    "messages": [{"role": "user", "content": [
      {"type": "text", "text": "..."},
      {"type": "image_url", "image_url": {"url": "data:image/jpeg;base64,..."}}
    ]}],
    "max_tokens": 800
  }'
```

**可用模型**（已验证）：
- ✅ `doubao-seed-2.0-pro` —— **首选**，快（2.5s/次），准确
- ✅ `doubao-seed-2.0-lite` —— 备选，更快但精度略低
- ✅ `kimi-k2.7` —— 中文 OCR 强
- ❌ `kimi-k2.6-claude` —— vision_analyze 用的，503
- ❌ `glm-5.2` —— 不支持 vision 参数

**批量视觉理解**：18 张关键帧，每张 4-6 句话描述，总耗时 179s（平均 10s/帧）。

## 附录：分析方法论

### A. 抽帧策略
1. **粗粒度**：每秒 1 帧（131 张）→ 用于发现大致动效窗口
2. **细粒度**：每 100ms 1 帧（前 30s 测试 + 30~130s 完整 = 1300 张）→ 用于精确定位动效时间戳

### B. 像素 diff 转场检测
- **阈值**：相邻帧像素 diff > 0.5% 视为动效存在；> 1.5% 视为动效峰值
- **滑动平均**：500ms 窗口平均 > 0.5% 持续 → 动效窗口聚类
- **合并规则**：间隔 < 500ms 的相邻窗口合并

### C. 视觉理解
- **模型**：`doubao-seed-2.0-pro`（qingxiaoyun，最稳定）
- **调用方式**：直接 curl（非 vision_analyze 工具）
- **每张帧 prompt**："这是视频 {时间点} 的截图。请简洁描述（4-6 句话）：1) 核心文字内容；2) 视觉元素；3) 配色与风格；4) 与上一帧对比的变化"
- **批次**：18 张关键帧，每张 4-6 句话，总耗时 179s（10s/帧）

### D. 量化分析
- **颜色直方图**：32 阶量化 → Top 10 颜色占比
- **版式布局**：8 行 × 4 列亮度矩阵 → 内容分布
- **文字密度**：横向梯度分析 → 文字行位置

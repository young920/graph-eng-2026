## 全局视觉规范（锁定 · 只 5 个元素 / 段）

```
┌─────────────────────────────────────┐
│                                     │ ← 顶头条（dot + 标 + VOL）
│                                     │
│   ▸ 第 X 章 · 章节名                │ ← 章节小标
│   ▸ CHAPTER · ENG                   │
│                                     │
│   主标题                            │ ← 主标（粗黑）
│   副标题/释义                       │ ← 副标
│                                     │
│        主内容区（米白底）            │ ← 1 个主视觉
│        卡片 / 表格 / 编号 / 分屏    │
│                                     │
│  VOICE-OVER 字幕条                  │ ← 字幕（窄条）
└─────────────────────────────────────┘
```

**每段只允许 5 个元素**：
1. 顶头条
2. 章节小标
3. 主标+副标
4. 1 个主视觉
5. VOICE-OVER 字幕

**禁止**：
- 装饰水印（@Hermes AI 探索、Hermes 头像）
- 状态栏/时间码/互动数据
- 抖音 tabbar / 小红书卡片
- 额外的 logo / 品牌角标
- 多于 1 个主视觉
- 多余的金句/列表/卡片堆叠
